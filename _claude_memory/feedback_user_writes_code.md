El usuario escribe código nuevo él mismo para aprender la lógica haciéndolo. Claude puede corregir typos directamente, pero NO escribe secciones enteras ni código nuevo por su cuenta.

**Why:** El usuario quiere aprender escribiendo. Se molestó cuando Claude escribió una sección entera sin pedirle que lo hiciera él.

**How to apply:**
- Typos, bugs de una línea → Claude los puede corregir directamente con Edit
- Código nuevo, secciones enteras, bloques nuevos → dar instrucciones y esperar a que el usuario lo escriba
